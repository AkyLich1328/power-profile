В планах добавление гистерезиса, для предотвращения колебания смены профиля, что бы не было спама по типу
86 градуса - ставлю power-saver
84 градуса - ставлю balanced
Решение проблемы примерно такое ->
- включаем power-saver при >= 85%
- выключаем только при <= 70%
